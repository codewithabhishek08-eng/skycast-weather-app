# 🌦️ SkyCast Pro

SkyCast Pro is a modern weather dashboard built using HTML, CSS, and JavaScript. It provides real-time weather information, forecasts, air quality data, and location-based weather updates through the OpenWeather API.

## 🚀 Features

* Real-time weather data
* Current location weather detection
* 24-hour forecast section
* Air Quality Index (AQI)
* Dynamic weather backgrounds
* Dark / Light mode
* Recent search history
* Responsive modern UI
* Weather condition animations
* Wind direction indicator
* Local storage support

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeather API
* Local Storage

## 📂 Installation

1. Clone the repository

```bash
git clone https://github.com/codewithabhishek08-eng/skycast-weather-app.git
```

2. Open the project folder

```bash
cd skycast-weather-app
```

3. Open `index.html` in your browser.

## 🔑 API Setup

This project uses the OpenWeather API.

Get your free API key from:

https://openweathermap.org/api

Add your API key in the JavaScript configuration section if required.
